# wsc3-text-fix

## v0.1.4: 動作確認済みv0.1.3を基準にした安全性修正

ユーザーによりv0.1.3でフリーズなし・改行補正ありと確認されました。v0.1.4ではその描画フック、補正条件、画面待ち条件を維持し、復元情報と失敗時の処理を補強しています。旧形式3の復元情報を引き続き使用できます。

破損・重複・不正な型・PID/作成時刻不一致・範囲外アドレスを拒否し、実際の専用メモリ領域も照合します。書込み・保護復元の失敗では元の値への復旧を試み、未確認の中継メモリは解放しません。スレッド列挙失敗や状態取得失敗を正常終了と誤認しないよう変更しました。

通常ログなし・ゲームフォルダーへの記録なしの仕様を維持します。ゲームと旧ランチャーを終了してから更新してください。v0.1.4自体の実ゲーム確認は未実施です。対策と限界は [SECURITY_V014_20261018.md](SECURITY_V014_20261018.md) を参照してください。

## v0.1.3: v0.1.1の改行補正を復旧

起動専用だったv0.1.2から改行補正を戻しました。補正コードとプロセス接続バックエンドはv0.1.1と同一です。PR #9の追加改修は取り込んでいません。

起動直後の接続を避けるため、対象PIDに属する画面が表示され、最小化されておらず、応答し続けることを2秒間確認してから、従来の描画コード照合と補正を行います。表示前や応答しない画面には接続しません。この条件は描画初期化完了やフリーズ原因の解消を証明するものではありません。

実際の32bit検証用プロセスで接続・幅補正・OFF・再接続・解除を検証しました。CPUエミュレーターでも高さ1〜512と隣接幅のON/OFF計3,072条件を検証しました。実ゲームを再起動する検証は行っておらず、ゲームでの起動・表示確認は未完了です。[検証記録](RESTORE_V011_20261018.md)を参照してください。

旧版が動いている場合はゲームとランチャーを終了してから置き換えます。`WSC3Launcher.exe --check` は対象EXEのファイル照合だけを行い、ゲームを起動・接続しません（正常0、未配置/不一致2）。

鋼鉄の咆哮3 Windows版の文章折り返しを補正する非公式ツールです。

ゲーム本体が正常に起動する環境で使用してください。このツールはゲーム本体や素材を含みません。元のゲームEXEファイル、SafeDiscの保護処理、WindowsシステムDLLは変更しません。

## ダウンロード・使い方

1. [Releases](https://github.com/mrky05321/wsc3-text-fix/releases) から最新版の `wsc3-text-fix-v*-win64.zip` をダウンロードします。
2. ZIP内の **WSC3Launcher.exe** を、元の **wsc3.exeと同じフォルダ**へ置きます。
3. 今後は **WSC3Launcher.exe** からゲームを起動します。

ランチャーは通常画面を表示せず、ゲームを起動して描画コードの準備後に自動補正します。ゲームが終了するとランチャーも終了します。問題がある場合だけ通知します。

既に同じフォルダのゲームが1つ動いている場合は、そのゲームへ接続します。別の補正ソフトを接続中の場合は、先に解除して閉じてください。Windows起動時の常駐登録は行いません。元のwsc3.exeから直接起動した場合、ランチャーは動きません。

## 補正内容

共通の文章描画処理について、最大文字幅がフォント高さの2倍の場合に「高さ＋1」へ補正します。対象高さは1〜512です。

| フォント高さ | 元の幅 | 補正後 |
|---:|---:|---:|
| 12 | 24 | 13 |
| 28 | 56 | 29 |
| 38 | 76 | 39 |

実行中のゲームメモリ内の命令を中継して補正します。対応EXEのSHA-256、前後の命令、描画クラス、内部出力バッファを照合します。別の描画経路を使う文章には適用されません。接続完了前の最初の描画まで補正する保証はありません。

全体補正ソフトでユーザーから表示改善の報告があります。専用ランチャーとしての起動・終了動作、全画面・全環境での表示は未確認です。ビルド成功はゲーム内動作の確認を意味しません。

## 対応環境

- ランチャー: Windows 10/11 x64
- 対象ゲーム: Windows版WSC3、32bit（x86）
- 対応wsc3.exeのSHA-256:
  `9a2a92e473e825b51a9d5bf657d84890e6d96ae3e586c8a5ce15c15514c3f4fc`
- 別バージョンは接続を拒否します。ゲームの起動互換性自体を修復するツールではありません。

ゲームが管理者権限ならランチャーも同じ権限で起動してください。自動昇格はしません。Windowsの警告やセキュリティ製品の判定が出た場合、保護を無効にせずソースと配布元を確認してください。EXEは未署名です。

## 記録と解除

通常版ランチャーは動作ログ・補正回数・文章の記録を保存しません。ゲームフォルダへのログ作成も行いません。Program Files内にインストールしたゲームにも配置できます。

強制終了後の安全な再接続に必要な小さな復元情報だけを `%LOCALAPPDATA%\wsc3-text-fix\<インストール場所の識別子>` に保存し、正常終了時に削除します。ディスク上の元EXEは変わらず、ゲーム終了でメモリ上の変更も消えます。検証用GUIの記録機能は従来どおり残しています。

強制終了後の再接続には同じ版と同じ復元情報を使用してください。接続中に `hook_*.json` を削除しないでください。復元できない場合はゲームを終了してください。ゲームを強制終了する機能はありません。

v0.1.0から更新する際はゲームと旧ランチャーを終了してからEXEを置き換えてください。旧版が残したログは自動削除しません。

補正を使わない場合は、ゲームとランチャーを終了してから元のwsc3.exeで起動します。手動で補正を切り替える計測GUIのソースも `src/app.py` に含めています。

## ソースからビルド

テストには `python -m pip install -r requirements-test.txt` の後、`python -m unittest discover -s tests -v` を使用します。Windowsの自作32bit検証EXEも含める場合は、環境変数 `WSC3_RUN_FIXTURE=1` を設定します。ゲーム本体は使用しません。

Windows x64、Python 3.10 x64を使用します。

```powershell
python -m pip install -r requirements-build.txt
python build.py
```

`release/WSC3Launcher.exe` と、EXEだけを含むZIPを生成します。第三者ライセンスはEXEに同梱され、リポジトリの `THIRD_PARTY_LICENSES` でも参照できます。

手動GUIは次で起動できます。

```powershell
python src/app.py
```
