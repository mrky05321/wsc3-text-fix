# wsc3-text-fix — v0.1.2 起動専用の応急版

PCフリーズの報告を受け、まず通常起動へ戻すための応急版です。
**この版では改行補正を一時停止しています。** 補正を再開する修正とセキュリティ改修は後続です。

`WSC3Launcher.exe` を元の `wsc3.exe` と同じフォルダーに置き、以前の検証ランチャーと置き換えて使用します。起動後はゲームだけが動き、ランチャーは終了します。ゲームが既に起動している場合は先に終了してください。

ゲームの起動だけを行い、自動接続、プロセスメモリの読書き、スレッド停止、フック、終了時の復元は行いません。ログ・復元情報の新規作成もありません。旧復元情報は削除しません。

ゲーム本体のEXE・SafeDisc・ゲーム資源・セーブは変更しません。ゲーム本体の起動互換性まで修復するものではありません。フリーズの原因自体は未特定であり、問題の接続処理を取り除いたことと、実ゲームでの起動成功は区別しています。

## 対応

- Windows 10/11 x64
- 元の32bit `wsc3.exe` のSHA-256:
  `9a2a92e473e825b51a9d5bf657d84890e6d96ae3e586c8a5ce15c15514c3f4fc`
- ZIPの内容は `WSC3Launcher.exe` だけです。

## ビルドと検証

```powershell
python -m pip install -r requirements-build.txt
python -m unittest discover -s tests -v
python build.py
```

自動テストは無害な代替プログラムの起動、引数・作業フォルダー、ゲーム未配置・別SHAの拒否、接続バックエンドが読み込まれないことを確認します。`WSC3Launcher.exe --check` はファイル検査だけを行い、ゲーム起動も通知画面の表示もしません。正常なら終了コード0、未配置/別SHAなら2です。

今回の問題が起きたPC上でゲームを再実行する検証は行っていません。元のゲーム自体の起動成功やフリーズ原因の解決は未確認です。

## 開発中の補正・安全性修正

`src/process_patch.py`、`src/hook_code.py`、`src/app.py` は旧補正実装のソースです。この応急版EXEは読み込みません。PR #9の安全性改修はこの変更に含めず、使用停止のまま別ブランチで保持しています。検証GUIも今回の代替起動方法として使用しないでください。

本ツールは非公式です。第三者ライセンスはEXE内と `THIRD_PARTY_NOTICES.md` / `THIRD_PARTY_LICENSES` にあります。
