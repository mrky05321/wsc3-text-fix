# wsc3-text-fix

鋼鉄の咆哮3 Windows版の文章折り返しを補正する非公式ツールです。

ゲーム本体が正常に起動する環境で使用してください。このツールはゲーム本体や素材を含みません。元のゲームEXEファイル、SafeDiscの保護処理、WindowsシステムDLLは変更しません。

## ダウンロード・使い方

1. [Releases](../../releases) から `wsc3-text-fix-v0.1.0-win64.zip` をダウンロードします。
2. ZIP内の **WSC3Launcher.exe** を、元の **wsc3.exeと同じフォルダ**へ置きます。
3. 今後は **WSC3Launcher.exe** からゲームを起動します。

ランチャーは通常画面を表示せず、ゲームを起動して描画コードの準備後に自動補正します。ゲームが終了するとランチャーも終了します。問題がある場合だけ通知します。

既に同じフォルダのゲームが1つ動いている場合は、そのゲームへ接続します。別の補正ソフトを接続中の場合は、先に解除して閉じてください。Windows起動時の常駐登録は行いません。元のwsc3.exeから直接起動した場合、ランチャーは動きません。

## 補正内容

共通の文章描画処理について、最大文字幅がフォント高さの2倍の場合に「高さ＋1」へ補正します。対象高さは1〜512です。

| フォント高さ | 元の幅 | 補正後 |
|---:|---:|---:|
| 12 | 24 | 13 |
| 28 | 56 | 29 |
| 38 | 76 | 39 |

実行中のゲームメモリ内の命令を中継して補正します。対応EXEのSHA-256、前後の命令、描画クラス、内部出力バッファを照合します。別の描画経路を使う文章には適用されません。接続完了前の最初の描画まで補正する保証はありません。

全体補正ソフトでユーザーから表示改善の報告があります。専用ランチャーとしての起動・終了動作、全画面・全環境での表示は未確認です。ビルド成功はゲーム内動作の確認を意味しません。

## 対応環境

- ランチャー: Windows 10/11 x64
- 対象ゲーム: Windows版WSC3、32bit（x86）
- 対応wsc3.exeのSHA-256:
  `9a2a92e473e825b51a9d5bf657d84890e6d96ae3e586c8a5ce15c15514c3f4fc`
- 別バージョンは接続を拒否します。ゲームの起動互換性自体を修復するツールではありません。

ゲームが管理者権限ならランチャーも同じ権限で起動してください。自動昇格はしません。Windowsの警告やセキュリティ製品の判定が出た場合、保護を無効にせずソースと配布元を確認してください。EXEは未署名です。

## 記録と解除

ゲームフォルダの `wsc3_launcher_logs` に起動・接続・補正回数・復元情報を保存します。ランチャーは本文を連続保存しません。ディスク上の元EXEは変わらず、ゲーム終了でメモリ上の変更も消えます。

強制終了後の再接続には同じ版と同じ復元情報を使用してください。接続中に `hook_*.json` を削除しないでください。復元できない場合はゲームを終了してください。ゲームを強制終了する機能はありません。

補正を使わない場合は、ゲームとランチャーを終了してから元のwsc3.exeで起動します。手動で補正を切り替える計測GUIのソースも `src/app.py` に含めています。

## ソースからビルド

Windows x64、Python 3.10 x64を使用します。

```powershell
python -m pip install -r requirements-build.txt
python build.py
```

`release/WSC3Launcher.exe` と、EXEだけを含むZIPを生成します。第三者ライセンスはEXEに同梱され、リポジトリの `THIRD_PARTY_LICENSES` でも参照できます。

手動GUIは次で起動できます。

```powershell
python src/app.py
```

## リリース

GitHub Actionsの「Build and release」でWindows用EXEをビルドします。`VERSION` を変更したpush、または手動実行で、そのバージョンのリリースとEXEだけのZIPを作成します。ゲームの実行テストは行いません。

本ツールは非公式であり、ゲームの権利者による承認・提供を示すものではありません。第三者コンポーネントのライセンスと著作権表示は `THIRD_PARTY_NOTICES.md` を参照してください。自作部分のオープンソースライセンスは現時点で未指定です。
